# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Nashordaq, please report it privately via email:

**security@kylehub.dev**

Include as much detail as possible: steps to reproduce, affected versions, and potential impact.

Please **do not** open a public GitHub issue for security vulnerabilities.

## Response

This is a personal project, so response times may vary. I will do my best to acknowledge reports promptly and work on a fix.
